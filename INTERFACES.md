## Market, pricing, sensitivities (Task A: curves.py, market_history.py, instruments.py, pricing.py, sensitivities.py, crif.py)
- `curves.py`: par-quote curve bootstrap at SIMM vertices (`bootstrap_curve(par_quotes) -> Curve` with zero rates, discount factors, par-to-zero Jacobian), NelsonSiegelCurve helper to generate par-quote levels.
- `market_history.generate_history(cfg=None, quick=False) -> MarketHistory`: 2,086 business days (2018-10-01..2026-09-30; quick from HIST_QUICK_START), 2-state Markov regimes (config persistence, stress vol multiplier, Student-t df 5), 3 PCA-style factors (level, slope, curvature) per currency with cross-currency correlation, FX log-returns, log-AR(1) vols linked to the regime, CDS log-spread jumps in stress; stress window of config.STRESS_WINDOW_DAYS; regime path saved. `MarketBatch` holds arrays with leading dimension n_states: par[ccy][n,12], zero[ccy][n,12], fx_spot[ccy][n], ir_nvol[ccy][n,expiry,tenor], fx_vol[pair][n,expiry], cds[n,5]; `history.batch(dates)`.
- `instruments.py`: trade table builder `sample_portfolio() -> DataFrame` with columns.TRADE_ID.. and `new_product_xccy()`.
- `pricing.price_portfolio(trades, batch) -> ndarray[n_states, n_trades]` (vectorized; IRS/XCCY from curves, swaptions Bachelier, FX forwards, FX options Garman-Kohlhagen), closed-form checks (Bachelier vega = A*sqrt(T)*phi(d); payer-receiver = forward swap; GK put-call parity and analytic vega/delta; at-par swap PV near 0; parallel PV01 near the sum of the ladder).
- `sensitivities.py`: IR delta per 1bp par quote by central difference +/- 0.5bp via the Jacobian method (zero-pillar deltas times d(zero)/d(par) from 12 re-bootstraps; test against full re-bootstrap); FX delta: +/- 0.5% relative spot bump in USD incl. translation risk; IR vega dV/dsigma_normal per 1bp vol, CRIF amount = sigma*vega allocated linearly to expiry vertices; FX vega lognormal per vol point (the SIMM engine uses sigma_SIMM = RW*sqrt(365/14)/Phi^-1(0.99)); curvature CVR = sum over j of SF(t_j)*sigma*vega.
- `crif.py`: `build_crif(trades, batch_row) -> DataFrame` with columns TradeID, PortfolioID, ProductClass, RiskType {Risk_IRCurve, Risk_XCcyBasis, Risk_IRVol, Risk_FX, Risk_FXVol}, Qualifier, Bucket, Label1, Label2, Amount, AmountCurrency, AmountUSD (use linear rebucketing, e.g. 7y = 60% 5y + 40% 10y).

## VaR IM, xVA VaR, backtesting (Task C: var_model.py, cva.py, backtest.py)
- `var_model.hs_im(history, trades, t, horizon=10, conf=0.99, window="eu_1plus3") -> float`: full revaluation under historical zero-rate, log-FX and vol changes (overlapping 10-day changes); window = most recent config.WINDOW_DAYS days with the oldest data replaced by the stress window until at least config.MIN_STRESS_SHARE is stressed, equally weighted; loss = -(V(t+h)-V(t)) on the frozen portfolio, no ageing (hypothetical P&L net of cash flows). `daily_simm_series(...)` (Jacobian batches per day, so SIMM itself is backtested). Challengers: EWMA-weighted HS (lambda 0.97), 250-day equal-weight HS with no stress, champion x config.CHALLENGER_SCALE.
- `cva.py`: hazard bootstrap from CDS 1/3/5/7/10y with R = 40%; netting-set EE for linear trades via closed-form normal approximation EE = mu*Phi(mu/s) + s*phi(mu/s); CVA = LGD * sum EE*DF*dPD. xVA VaR model: sensitivity-based HS (CS01 ladder, IR parallel delta, FX delta) at 1-day and 10-day vs realized full-revaluation change in CVA.
- `backtest.py`: `exceptions(loss, var)`, `kupiec_pof(x, n, p)` (LR = -2 ln[(1-p)^(n-x) p^x] + 2 ln[(1-x/n)^(n-x) (x/n)^x], 0 ln 0 = 0), `christoffersen(exc)` (LR_ind, LR_cc, p-values via Markov transition counts), `basel_zone(x, n, p=0.01)` (generic binomial rule: yellow where cumulative probability >= 95%, red >= 99.99%; BCBS 22 Table 2 plus factors for n = 250), `rolling(series, 250)`, `by_regime`, `shortfall_multiplier(loss, im)` (smallest k so that k*IM is Green), `run_battery() -> backtest_results.csv` with test dicts {test, model, split, value, threshold, light}. Designs: 1-day VaR vs 1-day P&L; 10-day IM vs 10-day P&L on NON-overlapping windows; overlapping 10-day windows reported with the BCBS 22 section II caveat. Lights: PASS if p >= 0.05 and Green; AMBER if 0.01 <= p < 0.05 or Yellow; RED if p < 0.01 or Red (worst governs). The mis-calibrated challengers must produce worse lights (shows power).
